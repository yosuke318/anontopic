# ADR-0024: 通報の分類から出会い目的（dating）を分ける

- ステータス: Accepted
- 日付: 2026-09-21
- 関連 issue: YOSUKE-131

## 文脈

[ADR-0015](0015-report-a-conversation-rather-than-a-participant.md) は通報の分類を
`sexual` / `contact` / `harassment` / `spam` / `other` の 5 つに固定し、出会い目的は
`sexual` に含めていた。

- YOSUKE-131 は分類を「出会い目的 / 性的表現 / 連絡先交換 / 誹謗中傷 / スパム / その他」の
  6 つとしている。
- 出会い目的の利用は、出会い系サイト規制法の対象にならないために排除すべき中心の行為で
  （要件定義書 3.1）、性的表現とは別に件数を追いたい。
- ADR-0015 は、分類を増やすときは削除ではなく追加で運用するとしている。
- NG ワード辞書の分類（`ng_words.category`）は既に `dating` と `sexual` を分けている。

## 決定

分類に `dating`（出会い・交際を目的とした書き込み）を追加し、`sexual` は性的な内容だけを指す
ようにする。値の並びは issue の順に合わせる。

既に記録された `sexual` の行は書き換えない。

## 検討した代替案

### 案A: 5 つのまま、`sexual` の表示文言だけを変える

変更は最小。ただし出会い目的の通報を単独で数えられず、規制法への対応状況を確かめる
材料にならない。

### 案B: 過去の `sexual` を読み直して `dating` に振り分ける

集計が揃う。ただし通報時に通報者が何を意図したかは記録に無く、振り分けには運営の推測が
入る。記録を推測で書き換えることは、監査・法対応目的で長期保持する `reports` の性質に合わない。

## 影響

- この変更より前の `sexual` には出会い目的の通報が含まれる。期間をまたいで集計するときは
  `dating` と `sexual` を合算して比べる。
- Go の定数・openapi・フロントの選択肢を同時に更新した。
