# ADR-0038: AdSense の広告ユニットを LP と紹介ページにだけ手動で置き、同意バナーは作らない

- ステータス: Accepted
- 日付: 2026-10-12
- 関連 issue: YOSUKE-143

## 文脈

- 設計書は Google AdSense での収益化を想定し、広告スクリプトを遅延読み込みしてチャット機能の
  性能への影響を抑えることを求めている（第 1 部 5 章、第 2 部 8 章）。
- AdSense のポリシーは、人同士の私的なやり取りが主目的の画面（ダイレクトメッセージ、ライブチャット、
  非公開のチャットルーム）への広告を禁じている。運営者のコンテンツが無い画面への広告も認めていない。
  `/rooms/` は前者、`/waiting` は後者に当たる。
- 読み物として成り立つページは `/`（LP）と `/about`。規約・ポリシー・申し立て・お問い合わせは
  手続きのページで、`/topics` は会話を始める操作の画面。
- 会話の画面には、`/` → `/topics` → `/waiting` → `/rooms/` とクライアント側の画面遷移でたどり着く。
  一度読み込んだ AdSense のスクリプトは、画面を移っても文書に残る。
- `next/script` の `worker` は Next.js 16 の App Router では動かない。
- 日本の利用者には、電気通信事業法の外部送信規律により、送信される情報・送信先・利用目的を
  通知または公表すれば足りる。同意までは求められていない。
- AdSense は EEA・英国・スイスの利用者にパーソナライズ広告を出すとき、Google が認定した
  TCF 対応の同意管理ツールを求める。AdSense の管理画面の「プライバシーとメッセージ」は認定済みで、
  広告のスクリプトから配信される。
- NEXT_PUBLIC_ で始まる値はビルドのときに埋め込まれ、フロントエンドは環境ごとにビルドする（ADR-0035）。
  AdSense の審査は prod のドメインで受ける。

## 決定

- 広告は AdSense の広告ユニットを `/` と `/about` の本文の途中に手動で置く。ボタンの近くには置かない。
  自動広告は使わず、管理画面で無効のままにする。
- AdSense のスクリプトは、広告枠を描いたページで `next/script` の `lazyOnload` で読み込む。
  広告枠は高さを先に確保し、配信されなかった枠は畳む。
- サイトの確認用の `google-adsense-account` の meta タグと `/ads.txt` は、発行者 ID がある
  ビルドでだけ出す。発行者 ID と広告ユニットの ID はビルドのときに渡し、prod にだけ渡す。
- 広告の Cookie は、プライバシーポリシーに外部送信規律の公表事項と AdSense が求める開示事項
  （第三者配信事業者の Cookie、オプトアウトの方法）を載せて扱う。独自の同意バナーは作らない。
  EEA・英国・スイスには AdSense の「プライバシーとメッセージ」の同意画面を出す。
- プライバシーポリシーの改定は掲示と改定日の表示で知らせ、`termsVersion` は上げない（ADR-0036）。

## 検討した代替案

### 案A: 自動広告を有効にする

配置を Google に任せられるが、スクリプトが残ったまま会話の画面に移ると、そこにも広告が差し込まれる。
会話の画面への広告はポリシー違反で、入力欄の近くへの差し込みは操作の妨げにもなる。

### 案B: 会話の画面の外枠（ヘッダーや入力欄の上）に広告を置く

最も閲覧時間の長い画面だが、私的なチャットの画面への広告はポリシーで禁じられている。
スクリプトの処理と広告の描画が、メッセージの描画と入力の応答に割り込む。

### 案C: 全ページに共通のバナーで Cookie の同意を求める

日本の利用者には公表で足り、同意は求められていない。LP に被さるバナーは、本文を覆うモーダルを
避けた ADR-0036 と同じ理由で SEO と審査に響く。EEA 等は AdSense の認定済みの同意画面で足り、
TCF 対応の同意管理を自前で作る理由が無い。

### 案D: 広告のスクリプトを root layout で全ページに読み込む

広告の無い `/waiting` と `/rooms/` に直接開いたときにもスクリプトを取得し、処理することになる。
広告枠のあるページでだけ読み込めば、会話の画面を直接開いたときには取得しない。

## 影響

- 広告の表示は `/` と `/about` の閲覧数に比例し、会話の利用量とは比例しない。収益は小さく見込む。
- LP から画面を移って会話を始めた場合、読み込み済みのスクリプトは会話の画面にも残る。
  広告ユニットが無く自動広告も無効なので、広告の描画は起きない。
- 自動広告を無効にしておくことと、欧州向けの同意画面を公開しておくことは、AdSense の管理画面の
  設定で、コードからは強制できない。README に手順として残す。
- 広告枠を増やす・自動広告を使う・`/topics` に置くときは、この ADR を見直す。
- 見直す条件: 会話の画面の初期表示や入力の応答が、広告のスクリプトが残った状態で悪化したとき
  （その場合は会話への遷移を全体の読み込み直しにする）。日本の法令が広告 Cookie に同意を求めるように
  変わったとき。
